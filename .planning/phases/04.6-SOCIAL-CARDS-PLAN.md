# Phase 4.6: Social Share Cards with Quick Wins

## Objective

Create shareable social media cards for DJs to showcase their sets and downloads, featuring the three council-approved "quick wins" plus user-customizable images.

## Ralph Loop Analysis

### R - Research
**Problem:** DJs want to share their sets/downloads on social media but need visually compelling cards
**Target:** Instagram, Twitter/X, Facebook stories
**Competitors:**
- Spotify Wrapped (highly viral)
- Apple Music Replay
- Beatport Top 10 cards

### A - Assess
**Quick Wins from Council:**
1. Video preview on hover - increases engagement
2. Download counts - social proof drives conversions
3. Camelot wheel - DJ credibility signal

**User Need:** Customizable image replacement for personal branding

### L - Learn
- Social cards need specific dimensions (1080x1080 for IG, 1200x630 for Twitter)
- Must work without React (static export for sharing)
- Canvas API best for image generation
- Need both preview AND downloadable formats

### P - Plan
**Deliverables:**
1. `SocialShareCard.tsx` - React component for preview
2. `SocialCardGenerator.tsx` - Canvas-based export tool
3. Image upload/replacement functionality
4. Multiple templates (Set Card, Download Stats, Genre Mix)

### H - Hypothesize
- Viral sharing will increase signups by 15-20%
- Custom images increase share rate by 3x
- DJs will share sets weekly during gig promotion

---

## Implementation Plan

### Step 1: Core Social Card Component
Create the visual card component with all three quick wins baked in.

**Features:**
- Customizable background image (user upload or preset)
- Download count display with animation
- Mini Camelot wheel showing set key range
- Video thumbnail grid preview
- TVP branding (subtle watermark)

### Step 2: Card Templates
Three template types:

**A. Set Card** - For sharing a DJ set
- Set name (customizable)
- Track count & total duration
- BPM range visualization
- Key compatibility ring (Camelot)
- Track thumbnail grid (2x3 or 3x3)

**B. Stats Card** - Monthly/weekly stats
- Download count (animated counter style)
- Top genres pie chart
- Favorite artists
- "DJ since [date]" badge

**C. Single Track Card** - For featuring a track
- Large video thumbnail
- BPM/Key prominent
- "Now Playing" or "Just Downloaded" badge
- Waveform preview

### Step 3: Customization System
- Image upload (drag-drop or file picker)
- Image crop/position tool
- Opacity/blur controls for overlay
- Color accent picker (defaults to TVP cyan)
- Text customization (set name, DJ name)

### Step 4: Export System
- Canvas-based image generation
- Multiple export sizes:
  - Instagram Post: 1080x1080
  - Instagram Story: 1080x1920
  - Twitter/X: 1200x630
  - Facebook: 1200x630
- PNG download with transparent option
- Copy to clipboard functionality

```

```
