## 🎯 Next Steps: 5-Minute Setup (That's It!)

### Step 1: Get Vercel Token (1 min)
- Go to: https://vercel.com/account/tokens
- Click "Create" → Give it a name (e.g., "GitHub Actions")
- Copy the token

### Step 2: Get Your Vercel Project IDs (1 min)
- Go to: https://vercel.com/dashboard/projects
- Click on "TVP-OC" project
- Settings → General
- Copy **Project ID** and **Org ID**

### Step 3: Get Railway Token (1 min)
- Go to: https://railway.app/settings/tokens
- Click "Create Token"
- Copy it

### Step 4: Add Tokens to GitHub Secrets (2 min)
- Go to: https://github.com/aundre1/TVP-OC/settings/secrets/actions
- Click "New repository secret" for each:
  ```
  VERCEL_TOKEN = <your vercel token>
  VERCEL_ORG_ID = <your org id>
  VERCEL_PROJECT_ID = <your project id>
  RAILWAY_TOKEN = <your railway token>
  ```

### Step 5: That's It!
- Next time you push code, **BOTH Vercel AND Railway deploy automatically**
- No more manual deployment commands needed
