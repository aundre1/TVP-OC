TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Q: "Error: No existing credentials found"
A: Run 'vercel login' to authenticate with your Vercel account

Q: "Build fails during deployment"
A: 
  - Verify npm run build works locally
  - Check Node.js version compatibility
  - Review build logs in Vercel dashboard
  - Check for missing environment variables

Q: "API connection fails after deployment"
A:
  - Verify VITE_API_URL is set in environment variables
  - Check API server is accessible from Vercel
  - Verify CORS settings on API server
  - Test API endpoint in browser console

Q: "Project won't link to Vercel account"
A:
  - Delete .vercel directory
  - Run 'vercel login' again
  - Run 'vercel link --yes'
