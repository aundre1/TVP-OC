TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Problem: "No existing credentials found"
Solution: Run 'vercel login' and follow browser authentication

Problem: Build fails during deployment
Solution: 
  1. Run 'npm run build' locally to test
  2. Check Node.js version compatibility
  3. Review build logs in Vercel dashboard
  4. Check for missing dependencies

Problem: API calls fail after deployment
Solution:
  1. Verify VITE_API_URL environment variable is set
  2. Check API server is accessible from Vercel
  3. Test API endpoint: curl https://api-staging.thevideopool.com
  4. Verify CORS settings on API server

Problem: Large bundle size warning
Solution:
  1. Current: 617 kB (184 kB gzipped) - Acceptable
  2. Monitor bundle growth
  3. Use code-splitting for large features
  4. Consider lazy loading components
