🔴 BLOCKING: PostgreSQL Connection String Not Set on Railway

The backend needs DATABASE_URL environment variable to connect to Supabase.

Where to get it:
1. Go to https://app.supabase.com/dashboard
2. Select project: jvgsmiqsqtqgfagghoiv
3. Click Settings → Database → Connection string
4. Copy the PostgreSQL URI
5. Add to Railway as DATABASE_URL

Format will be:
  postgresql://postgres:PASSWORD@db.jvgsmiqsqtqgfagghoiv.supabase.co:5432/postgres
